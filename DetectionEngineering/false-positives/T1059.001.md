# T1059.001 - Encoded PowerShell Detection

## 1. Objective

Detect PowerShell execution where the command is supplied using an encoded command parameter.

## 2. MITRE ATT&CK Mapping

Technique ID: T1059.001
Technique: PowerShell
Tactic: Execution

## 3. Log Source

Operating System: Windows
Log Source: Sysmon
Event ID: 1 - Process Creation

## 4. Detection

Detection format: Sigma
Detection engine: Chainsaw
Rule: T1059.001_encoded_powershell.yml

The detection looks for PowerShell or PowerShell Core being launched with an encoded-command parameter such as -e, -en, -enc, -ec or -encodedcommand.

## 5. Attack Simulation

Atomic Red Team was used to generate controlled PowerShell activity associated with T1059.001.

The simulated activity generated Sysmon process-creation telemetry.

## 6. Detection Result

The Sigma rule was validated using Chainsaw.

The encoded PowerShell activity was successfully detected in the collected Sysmon telemetry.

## 7. Benign Activity Test

A normal PowerShell command was tested:

Get-Process

The tested benign activity did not satisfy the encoded-command conditions of the Sigma rule.

## 8. False-Positive Observation

No false positive was observed in the specific benign scenario tested.

This does not establish that the rule has zero false positives in all environments. Additional legitimate administrative and software-management activities should be tested.

## 9. Current Conclusion

The detection successfully identified the tested encoded PowerShell behavior while not triggering on the tested Get-Process activity.

Further testing will be performed using additional legitimate activities to evaluate potential false positives and determine whether detection tuning is required.
